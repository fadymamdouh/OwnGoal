# النسخة الأونلاين على GitHub Pages + Firebase

لينك ثابت مجاني بلا كارت وبلا سيرفر. الفولدر ده لوحده هو الموقع كله.

## الرفع

1. ارفع الريبو على GitHub (لازم **public** عشان Pages المجاني).
2. `Settings → Pages → Source: Deploy from a branch → main → /(root)` واحفظ.
3. اللينك هيبقى: `https://<username>.github.io/<repo>/web/`

## قواعد الأمان — خطوة مش اختيارية

افتح `Realtime Database → Rules` في كونسول Firebase، والصق محتوى
`database.rules.json` من جذر المشروع، واضغط **Publish**.

من غير الخطوة دي القاعدة مفتوحة أو مقفولة بالكامل — وفي الحالتين اللعبة مش
هتشتغل صح. القواعد دي بتضمن إن كل لاعب **يقرا حالته هو بس**، ومايقدرش يبعت
حركة باسم حد تاني.

## قبل أول تشغيل

- `Authentication → Sign-in method → Anonymous` لازم يكون **مفعّل**.
- في `web/firebase-config.js` اتأكد إن `databaseURL` مطابق للـ URL اللي ظاهر فوق
  شجرة البيانات في الكونسول (بيختلف حسب المنطقة).

## إزاي بتشتغل

مفيش سيرفر، فلاعب واحد لازم يكون الحكم. **اللي بيعمل الأوضة هو المستضيف** —
بيشيل حالة اللعبة، وبينفذ الحركات، وبينشر لكل لاعب **حالته هو بس**. اللاعب التاني
عمره ما بياخد كروت خصمه، هو بس بيبعت حركاته والمستضيف بينفذها ويرد.

```
/rooms/{code}/meta          مين المستضيف، المود، الوضع
/rooms/{code}/players/{uid} الاسم والخانة
/rooms/{code}/views/{uid}   حالة اللاعب — مقروءة له لوحده
/rooms/{code}/actions/{id}  الحركات المرسلة، المستضيف بيستهلكها
```

**الحد المعروف:** المستضيف شايل الديك في الميموري، فهو نظريًا يقدر يشوف ترتيب
الكروت الجاية. ايد خصمه مستورة عنه بقواعد الأمان، لكن الديك لأ. مع الأصحاب مش
مشكلة؛ للنشر العام محتاج سيرفر (`scripts/server.py` جاهز لكن محتاج استضافة).

## اللعب ضد البوت

مبيلمسش Firebase خالص — كله في متصفحك، بيشتغل حتى بلا نت بعد أول تحميل.
